# Methods

We created a small in-memory graph for a redwood and an example grove
and added the directed relationship `grows_at`. We read the native
JSON string, parsed the GraphML with the locked XML parser, and
checked the entity and relationship records in the CSV results.

The same fixture and assertions appear in the
[graph walkthrough](https://github.com/docxology/ultralink-docx/blob/main/docs/getting-started/quick-start.md).
The numerical record identifies the checked Node runtime and the
observed row counts. The example needs no web service.
