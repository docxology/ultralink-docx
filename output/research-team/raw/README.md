# raw

The pipeline's raw data export for the research-team sample: `research-team.json`.

- `src/research-team/pipeline.js` names this folder as its `raw` silo and describes it as
  the raw data export for JSON and CSV; the CSV form lands in the `csv` silo beside it.
- Regenerate by re-running the pipeline rather than editing the file.
  [`../../README.md`](../../README.md) lists the silos.
