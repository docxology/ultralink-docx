# Graph data for model integrations

The graph library exports structured entity and relationship records.
An application can use those records as bounded context for a separate
model integration. Select the fields required for the application and
preserve stable identifiers so returned references can be checked.

The [data export walkthrough](../getting-started/quick-start.md)
exercises the normal export API. The [model data example](../tutorials/llm-integration.md)
describes the structured data boundary.
