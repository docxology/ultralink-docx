# html-website-custom

One committed file, `styles.css`: the stylesheet of a customised HTML website export.

- The HTML pages that stylesheet belongs to are not committed here, so this folder is a
  fragment of an example export rather than a site you can open.
- The exporter that produces this kind of site is `toHTMLWebsite`, in
  `src/lib/exporters/html-website.js`; nothing in `src/` or `scripts/` names this
  particular folder.
- The sibling folder is [`../obsidian/`](../obsidian/).
