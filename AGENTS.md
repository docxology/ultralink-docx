# Working on UltraLink

Start with the [docs hub](docs/README.md) and the
[development verification guide](docs/contributing/development-setup.md).

Library entry points live in `src/`. Tests live in `tests/`, with
generated example and test exports kept apart from maintained docs.
Use the nearest directory guide when editing a package or example.

Keep maintained guides under `docs/`, with authored publication files
in `docs/manuscript/`. The root [backlog](TODO.md) tracks open work.
Historical exports, validation reports and examples preserve their
published meaning. Verify any changed API example against the locked
checkout.
