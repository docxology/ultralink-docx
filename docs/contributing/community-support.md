### GitHub Issues

For bug reports and feature requests, use the [UltraLink issue tracker](https://github.com/docxology/ultralink-docx/issues). Search for an existing issue before opening a new one.

When reporting bugs, please include:
- UltraLink version
- Environment details (Node.js version, browser, OS)
- Minimal reproducible example
- Error messages and stack traces
- Steps to reproduce the issue
