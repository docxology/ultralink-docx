# reports

Validation reports from the repository's own scripts: one folder, `validation/`.

- `validation/` holds the JSON and HTML pairs written by
  [`../scripts/validate-renderers.js`](../scripts/validate-renderers.js); its guide is
  [`validation/README.md`](validation/README.md).
- The folder is not a build artifact of a test run: the pairs are committed per run and
  nothing prunes them.
