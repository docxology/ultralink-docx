# assets

The dashboard's network diagram: `network-overview.graphml`, one file.

- It is written with the rest of the dashboard by `generateNetworkOverview` in
  `src/research-team/dashboard.js`, which creates this folder. The dashboard's own guide
  is [`../README.md`](../README.md).
- GraphML is the editable form of the diagram; nothing in the repository rewrites or
  verifies it separately from the dashboard run that produced it.
