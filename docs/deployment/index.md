# Static HTML exports

The library's `toHTMLWebsite()` method generates a collection of files
for a static graph site. Preserve the filenames and their relative
locations when writing the export. Start with `index.html` and check the
links and assets before sharing the directory.

The [HTML website format guide](../formats/HTML_WEBSITE_FORMAT.md)
describes the exporter. The [installation guide](../getting-started/installation-guide.md)
covers the local environment. Use a full build for the visualization
features and test the intended browser and asset configuration.
